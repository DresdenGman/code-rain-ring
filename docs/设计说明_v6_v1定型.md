# 代码雨戒指 v6 / 产品v1 定型说明

## 1. 项目拆分
- 开发板(桌面调试，已购)：ESP32-C3 + 0.42" OLED 开发板、TP4056 Type-C 充电板、TTP223 模块、400909 35mAh(9x9x4)电池。仅用于写代码/调动画，不进戒指。
- 产品v1：本文件 + BOM_v1_定型.csv。

## 2. 外形(与v4/v5完全一致)
直壁U形印章，侧视两侧平行竖边，无锥度；长17 x 宽24.6 x 高27.1；头部高出手指4.5mm；无按键孔、无USB孔。唯一开口=内圈顶部的Φ4磁吸充电口(朝手指，取下戒指充电)。
后端面在4.5mm头高时手指上方只有4.5mm，Φ4孔+盖板凹槽/圆角后余量约0.25mm，不可行 → 放内圈(底盖)上。

## 3. 内部布局(z自手指轴向上，指圈半径10.3)
| 层 | z |
|---|---|
| 底盖(含Φ4.1孔) | 10.3–10.9 |
| 磁吸母座 Φ4x2.0(端面内缩0.1) | 10.4–12.4 |
| PCB底面器件区(MCU/加速度计/充电/保护/LDO) | 10.9–12.4 |
| PCB 0.4mm，15.0x14.4 R0.8 | 12.4–12.8 |
| 屏FPC折叠层 | 12.8–13.1 |
| 0.49" OLED 14.5x11.6x1.28(背胶贴在盖板下) | 13.1–14.4 |
| 盖板玻璃 19x13 t0.4 | 14.4–14.8 |
两侧电池腔各放1只 2x8x15，贴外壁放置(y=±9.5~11.5, z=5.65~13.65)。

## 4. v6几何修正
- v5的电池腔下部在 |y|=7.4~9.2 处与指孔连通(底盖盖不到，会漏缝看到电池)。v6改为电池腔与指孔之间保留0.7mm壁，已用SDF逐点检查内圈无开口。
- 电池腔顶抬到13.9。OLED腔改为0.49寸用 14.8x11.9。

## 5. 选型理由
- MCU：ATtiny1616(无射频)。直接电池供电1.8V起，休眠0.1µA，megaTinyCore可用Arduino，UPDI单线烧录。CH32V003更便宜但最低2.7V、待机电流更高，作备选。
- 唤醒：加速度计敲击(SC7A20 / LIS2DH12)单击/双击中断。金属外壳整体贴着手指，电容触摸(TTP223/MCU触摸)会一直被触发或受金属屏蔽，且需要开孔/非金属区，不用。
- 充电：TP4054约15mA(2x9mAh的1C≈18mA，20–40mA过大)；XB5353A每节一颗。
- 屏：0.49" 64x32 显示区11.18x5.58，大于0.42"(9.2x5.2)，盖板19x13下可容纳 → 定型0.49"。0.42"(12x11)也能装，作备选。FPC直接焊PCB(无连接器，厚度不够)。

## 6. 电池
- 2mm厚 200815 国内可买(1688约¥12/只)，需样品确认极耳长度。
- 400909(9x9x4)放不进：侧腔仅4.5宽 x 约8.3高(内侧受指孔圆弧限制)，头部内腔高仅约2mm可用。要放400909需头部加高约5mm或外宽加大，会破坏v4外形 → 只用于开发板。

## 7. PCB打样(嘉立创)
0.4mm板厚 沉金，15.0x14.4 圆角R0.8；单面(底面)贴片，0402 + QFN-20 + LGA-12 + SOT-23；嘉立创SMT可贴(LGA/QFN需选"经济型/标准型"按其规则)。母座、屏FPC、电池手工焊。留UPDI/GND/VCC测试点。
