# CodeRain v9 —— 金属面框盖住屏幕非发光边 (基于 v8 v1定型, 仅改屏幕窗口)
## 改了什么
- 顶面改为**整块连续金属板**, 中间开矩形窗口 **13.6(横向Y) x 10.3(沿手指X)**, 圆角 R0.5, 顶缘 0.15x45° 内倒角(顶面开口 13.9x10.6)
- 屏幕发光区 AA 13.42x10.06 (64x48), 长边横跨手指(与v8一致); 窗口比AA每边大约 0.09(Y)/0.12(X), 比VA 14.42x11.06 小 → 屏幕非发光黑边全部被金属盖住, 露出的=能亮的全部
- 玻璃顶面比金属顶面**低 0.50** (金属 z14.80, 玻璃 z13.90–14.30), 侧看金属边框高于玻璃
- 窗口中心 x=+0.8 (对准AA中心); 屏幕整体比v8向 -X 移 0.5 (中心 x=-0.2), FPC弯折余量 -X侧 1.2
- 面框宽度: 横向两侧各 5.50; 沿手指 -X(FPC侧) 5.95 / +X 4.35 (AA相对屏中心偏 +1.0 为按图纸估算, **待卖家规格书确认**, 确认后只需改 aa_off 一个参数)
- 窗口/戒面面积比 = 140.1 / 506.8 = 27.6% (AA/戒面 26.6%); v8 玻璃/戒面 73.6%
## 零件与装配 (顶部装入)
- 主体 unibody (z<13.9, 顶部开口 19.0x23.0 R1 = 内壁) + **顶框 top_bezel** (z13.9–14.8, 整个戒面含外圆角, 带0.25定位唇, -X侧唇断开让FPC) + 底盖(不变) + 玻璃 13.0x16.4 R0.8 t0.4 (外购, 无需丝印黑边)
- 分模线在头部四周侧面, 距顶面 0.9, 顶面无缝
- 顺序: 电池x2 放入两侧腔 → 磁吸座装底盖/底盖装入 → PCB 从顶部放入(z12.0–12.4) 焊电池/磁吸座 → 屏FPC焊PCB顶面并从-X边下折, 屏落位(z12.62–13.85, 下垫0.2泡棉) → 玻璃用OCA/UV胶粘入顶框背面 13.1x16.5 深0.4 凹槽(粘接边≥1.3) → 顶框盖上, 唇定位, 结构胶(DP460)或激光点焊/环焊封边, 抛/喷砂修分模线
- 为什么不从底部装: 底盖口 Y 仅14.8 < 屏16.5 / PCB 18.6, 放不进; 顶部一体封死则无法装屏
## 为腾出下沉做的内部变化
- 头高 4.5、戒面 24.6x20.6、外形 20.6x24.6x27.1 **不变**
- PCB 下移 0.4 (v8 z12.4–12.8 → v9 12.0–12.4); 屏下移 0.48; 电池腔/磁吸座/底盖/指圈不变; 电池腔上方0.5金属托板取消(改为顶部开口, 由顶框唇压住)
## 重量
- 主体 2516.7 + 顶框 290.1 + 底盖 177.8 = 2984.6 mm³ (v8 2857.0, +127.6)
- 316L ≈23.8g (v8 22.8) / Ti ≈13.2g (12.7) / 925银 ≈31.0g (29.7); 玻璃 0.21g (v8 0.37g)
## 风险/待确认
- AA 相对面板的偏移(aa_off) 与 13.42x10.06 实际位置 → 窗口对位公差仅 ±0.1, 建议到货屏实测后再定窗口; 装配时需治具对位
- 窗口开口与发光区仅差0.1, 斜看会有边缘遮挡(下沉0.5+玻璃0.4)
- 顶框最薄处: 窗口边 0.5 金属, 打印需注意变形; 顶框与主体配合需单边 0.05 间隙(模型已含唇0.05)
- PCB 支撑台阶 v8 起即未建模
