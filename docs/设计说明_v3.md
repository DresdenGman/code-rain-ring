# Code Rain 代码雨戒指 · 设计说明 v3（一体式金属机身）

## 1. 关键改动
- **外壳**：面头和戒圈合成**一个连续的整体外壳**（SDF smooth-union，过渡圆角约 R2.6，顶边圆角 R0.5）。顶面和侧面没有接缝、没有螺丝。
- **戒圈**：平带 6.0×1.6 mm，边缘 R0.6，底部开口 8 mm，靠金属弹性调节 US 9–13。内径 20.6。
- **顶面**：近方形 18.6×18.0，圆角 R3.6，侧面向下内收 17°。
  - 黑色玻璃镜片 15.4×12.2×0.55，**与顶面齐平**。
  - 可见边框：左右约 1.6 mm，上下约 2.9 mm。
- **底盖**：可拆，藏在戒指内侧（手指面），底面贴合手指弧度，2 颗 M1 螺丝。顶面和侧面看不到。
- **USB-C**：开在后斜面（-X），正面和侧面看不到。
- **高度**：**顶面距手指 8.3 mm**，低于 8.5 mm 的目标。
- **内部堆叠**（底盖顶面 z = 11.0）：
  - 电池 201212，z 11.0–13.0
  - PCB + 中置 USB-C 区，z 13.1–16.75
  - OLED，z 16.75–18.05
  - 镜片，z 18.05–18.6
- **体积和重量**：体积约 1.16 cm³。估算重量：316L 约 9 g，925 银约 12 g，钛约 5 g，铝约 3 g。

## 2. 唤醒方式：加速度计敲击
- **SC7A20HTR**（士兰微），立创 **C19274408**，LGA-12 2×2，USD 0.29，有单击/双击中断。
- 备选：**LIS2DH12TR**（ST），立创 **C110926**。
- 接法：INT1 接 CH32V003 的 EXTI 引脚，用于从 standby 唤醒；I2C 与 OLED 共用总线。
- 待机：低功耗模式约 2 µA（手册值；实际取决于 ODR，**未实测**）。
- 好处：金属机身上不用开任何孔，"双击亮屏 10–15 秒"完全靠固件。
- 风险：日常动作可能误触发。需要调阈值和时间窗，必要时改为必须双击。

## 3. 续航（估算）
与 v2 相同：10 mAh 电池，每天点亮 30 次，约 7–8 天；常亮约 1.5–2.8 小时。

## 4. 制造
- **925 银失蜡**（推荐首选），或 **316L MIM / 精铸**：铸造后 CNC 精修镜片台阶（深 0.55 ± 0.03）、内腔和 USB 口，然后喷砂。
- **钛 / 铝 CNC**：外形是自由曲面，需要五轴加工；内腔从底部铣出。
- **戒圈弹性**：
  - 925 银较软，反复掰开会疲劳。建议加厚到 1.8 mm，或改用 316L / 钛。
  - 弹性开口只能小范围调节。US 9–13 跨度较大（内径 18.9–22.2），**单一尺寸是否舒适未验证**，可能需要分 S/L 两个码。

## 6. 未决问题
1. STEP 是网格 STEP，需要重建为曲面 STEP。
2. 高精度 STL 在 trimesh 检查中不是严格水密（marching cubes 的伪影），送 3D 打印前要修复（Blender 3D-Print 工具或 Netfabb）。
3. 底盖与机身之间暂未留装配间隙，开模前要加 0.05–0.1 mm。M1 螺丝的螺柱尚未建模。
4. USB-C 开口与 PCB 的位置要在 PCB 布板后核对。
5. 加速度计敲击的误触发率需要原型验证。
