# 代码雨戒指 v5 设计说明

## 变更（相对v4）
- 外形完全沿用v4直壁U形印章：侧视平行竖边、无锥度，长度17mm恒定，带宽外径24.6mm。唯一改动：头部高出手指 5.5→4.5mm（z_top 15.8→14.8），整体高 27.1mm。
- 取消USB-C开孔；改为2P磁吸pogo充电，母座(LCSC C5280828，高2.8mm)装在内圈顶部底盖上，触点朝手指，沿手指轴向布置（曲面弓高≈0.5mm），中心 x=-1.9。顶面/侧面/后端面无任何开孔。
- 后端面在4.5mm头高时只剩约3mm材料，放不下约11x6.5mm母座，故选内圈。

## 叠层（自手指向上，mm）
底盖10.3–10.9 / PCB 11.0–11.6（器件至≈12.4，C形板绕开pogo）/ pogo本体顶13.1 / OLED 13.2–14.4 / 盖板14.4–14.8

## 电源
TP4054(C382138) + R_PROG 68k ≈15mA（估算）；XB5353A(C80628)每节电池一颗。用户要求的20–40mA超过2×9mAh的1C(≈18mA)，不建议。触点接VIN，串肖特基+ESD，镀金。
电池 LIP-020815 可在1688等购得；腔体长15.4mm，极耳需折弯，须样品验证。
